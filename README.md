# Calculating Riemann Sums

This project explores Riemann sum approximations using Julia. Four functions — x² − 1 on [0, 2], −x² on [0, 1], sin(x) on [−π, π], and sin(x) + 1 on [−π, π] — are each partitioned into four equal subintervals, and the resulting rectangles are visualized using left-hand endpoints, right-hand endpoints, and midpoints as sample points; the project also covers computing the norm of a non-uniform partition. For the full report with plots and calculations, see [`calculating_sums.pdf`](./calculating_sums.pdf).
